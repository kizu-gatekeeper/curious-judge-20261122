# Curious — Lighthouse Keeper

A one-paragraph hook that makes the AI judge curious. A Python program that writes a single short, unfinished-feeling text to `/output/entry.txt`: a warm kettle, two cups, a logbook warning not to answer something that came back — and a pencilled reply that stops mid-sentence.

Run with `python3 main.py`; output goes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
